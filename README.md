# Playlist Manager

A Python project focused on Object-Oriented Programming (OOP), designed to manage music registrations and create playlists through a structured application architecture.

## Overview

This project explores the development of a music playlist management application using Python. It applies object-oriented principles and separates the application's responsibilities into different components, making the code easier to understand, maintain, and extend.

The application currently focuses on:

- Registering music.
- Managing music entities through a repository.
- Creating playlists.
- Connecting user interfaces to controllers.
- Coordinating application workflows through a process handler.

## Features

- **Music Registration:** Register music through a dedicated interface and controller.
- **Music Repository:** Organize and manage registered music using a repository.
- **Playlist Creation:** Create playlists using the available music collection.
- **Structured Architecture:** Separate the application's models, views, controllers, and process handling.

## Project Architecture

The project follows a Model-View-Controller (MVC)-inspired architecture, with additional components for repository management and application workflow coordination.

| Component | Responsibility |
|---|---|
| `Model` | Contains music entities and repository logic. |
| `View` | Handles the user interface for music registration and other application interactions. |
| `Controller` | Processes user actions and connects the views to the model. |
| `Repository` | Provides a centralized way to manage music data. |
| `Process Handler` | Coordinates the application's main workflow and connects the different processes. |
